# Control Académico – Frontend (Angular 20 + PrimeNG + Tailwind)

Este proyecto es el **frontend del sistema de Control Académico**, desarrollado en **Angular 20 (standalone)** usando **PrimeNG** para componentes UI y **Tailwind CSS** para estilos.  
Consume la API REST construida en **ASP.NET Core 10 + MySQL**.

Permite administrar:
- Usuarios
- Asignaturas
- Horarios (Schedules)
- Vista semanal de clases

---

## 1. Requisitos previos

Antes de ejecutar el proyecto debes tener instalado:

- **Node.js 20+ (recomendado)**
- **Angular CLI 20+
- Navegador moderno (Chrome, Edge, Firefox)
- Backend del proyecto ejecutándose

Verificar versiones:

```bash
node -v
npm -v
ng version
